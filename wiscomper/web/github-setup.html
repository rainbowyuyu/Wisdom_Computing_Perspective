WISCOMPER · 本机设置

连接你的 GitHub 账号

先创建 GitHub OAuth App，再通过本机终端保存凭据。完成登录后，当前浏览器的作品会归入你的账号。

1

创建本机 OAuth App

打开 GitHub 开发者设置 ↗，进入 OAuth Apps。已有应用可直接打开检查；否则选择 New OAuth App 并填写：

Application name
Wiscomper Local
Homepage URL
http://127.0.0.1:3088
Authorization callback URL
http://127.0.0.1:3088/api/auth/github/callback

注册后，页面会显示 Client ID。选择 Generate a new client secret，并保留页面，供下一步在本机终端输入。

2

在本机保存凭据

打开项目文件夹，双击 配置GitHub登录.cmd。已有 Client ID 时直接按回车保留，再粘贴新生成的 Client Secret。输入过程不会显示字符。

也可以在项目目录运行：

& .\.venv\Scripts\python.exe .\scripts\configure_github.py

凭据只保存在本工程的服务端配置文件中。请在终端填写 Secret，不要发到聊天、网页表单或截图中。

3

重启并登录

重启工作台服务，再统一打开 http://127.0.0.1:3088，点击账号菜单中的「继续使用 GitHub」。登录往返请使用同一个浏览器和地址。

本机检查命令如下，只报告配置是否齐全，不显示凭据：

& .\.venv\Scripts\python.exe .\scripts\configure_github.py --check

检查通过后，仍需完成 GitHub 授权才能验证实际登录。工作台仅请求读取基本公开资料的权限，不申请仓库或邮箱权限。

遇到问题

「GitHub 登录尚未配置」：确认已填写 Secret，并重启服务。「登录验证已过期」：回到工作台重新开始登录。已有任务正在运行时，先等待任务完成或取消任务。

此页适用于本机 3088 端口。公网部署应使用单独的 OAuth App、HTTPS 回调和部署配置。完整说明在项目 docs/github-local-setup.md。
