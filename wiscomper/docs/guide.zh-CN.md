# Wiscomper 智算视界 · Wisdom Computer Perspective

[返回中文介绍](../README.md) · [English overview](../README.en.md) · [快速开始](../README.md#quick-start)

让万物，动起来。Wiscomper 智算视界把文字、公式和图片变成可观察、可交互、可继续探索的动态世界。英文全称为 **Wisdom Computer Perspective**。这是独立的可视化工作台，默认在本机运行，地址为 `http://127.0.0.1:3088/`；正式域名、HTTPS 反向代理与 GitHub 登录配置见 [公网部署说明](deployment.md)。

本项目拥有自己的 Python 环境、npm 依赖、网页、会话、任务队列、模型适配器和数据目录。运行时不导入旧网站或 OmniForge 的源码；部署时可以连接旧站 MySQL，继续使用原邮箱账号和权限，并迁入公式、笔记及错题。OmniForge 仅作为 DSH 集成方式的参考。替换旧站且保留原配置与数据库，请使用 [部署包说明](../deploy/DEPLOY-PACKAGE.md)。

## 安装与启动

本机启动器需要 Windows、PowerShell 7、Python 3.11+ 和 Node.js 22.19+（22系列，或24及以上）；推荐 Node.js 24。Linux 服务器使用部署包入口，无需 Windows 或 PowerShell。以下命令在新工作台的项目根目录执行，也就是仓库中的 `wiscomper/`，不要在 `docs/` 目录中运行：

```powershell
py -3 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt
npm ci
```

安装好环境后，双击项目根目录的 **`万象世界.exe`** 启动并打开浏览器。这个原有文件名保留为兼容入口，网页品牌已更新为 Wiscomper 智算视界，无需重新编译启动器。已有服务运行时会直接打开，不会重复启动。启动过程中显示简短提示，不弹出命令行窗口；失败时会提示日志位置。

EXE 只是启动入口，每次读取旁边最新的 `Start.ps1`，网站和 Python 代码都保留在外部。**更新网页、服务和启动脚本不需要重新编译 EXE**。更新前先停止服务，替换文件后重新双击 EXE；保留 `.env`、`data/` 和本机依赖环境，有依赖变更时按更新说明安装。EXE 本身不会下载更新，也不包含 Python、Node.js 或网站文件。

请把 EXE 留在项目根目录；需要桌面入口时，给它创建快捷方式。它会自动寻找 PowerShell 7；找不到时可编辑同目录 `launcher.ini` 的 `PowerShellPath` 指向已有的 `pwsh.exe`，不必重编。项目整体迁移或换电脑仍需重新配置依赖环境，不能只复制 EXE。

双击 `Stop.cmd` 停止该入口管理的进程树。`Start.cmd` 仍可作为终端启动入口；两个 CMD 入口要求 PowerShell 7 在 PATH 中。也可在终端运行（`pwsh` 不在 PATH 时使用 `launcher.ini` 中指定的完整路径）：

```powershell
pwsh -NoProfile -File ./Start.ps1
pwsh -NoProfile -File ./Start.ps1 -NoBrowser
pwsh -NoProfile -File ./Stop.ps1
```

指定其他端口时，启动和停止使用相同参数：

```powershell
pwsh -NoProfile -File ./Start.ps1 -Port 3090 -NoBrowser
pwsh -NoProfile -File ./Stop.ps1 -Port 3090
```

启动器只运行本工程 `.venv/Scripts/python.exe` 和 `main.py`，窗口隐藏，固定绑定 `127.0.0.1`。重复启动会检查 `/healthz` 的 `app=visualize-dsh`、监听进程和工程归属后复用。端口被其他服务占用时会报错，不会关闭对方。停止前会核对 PID、创建时间、Python 路径和完整入口命令，避免误停复用 PID 或其他工程。

启动器状态和日志位于 `data/service/`。已经手动启动的本工程服务可以复用，但不会被收编为启动器可停止的进程；手动启动的终端仍负责结束它。停止入口会终止本服务的在途模型和渲染子进程；重启后未完成任务标记为中断，不自动重发模型请求。

EXE 的可选参数为 `--no-browser`（只启动服务）、`--port 3090`（指定端口）和 `--quiet`（不显示界面，退出码与日志反映结果）。启动日志为 `data/service/logs/launcher-*.log`；项目目录不可写时退回当前用户的 `%LOCALAPPDATA%/WisdomPerspective/launcher-logs/`。源代码与可选构建脚本在 `launcher/`，仅修改启动器本身时才需要运行 `launcher/build.ps1`。

不需要模型配置即可使用首页本地案例、播放、参数重算和浏览已有作品。输入自己的描述或图片时才会调用所选模型。

## 模型连接

官方 DeepSeek Harness 固定为 **`@deepseek-ai/dsh@0.2.0-rc.2`**，记录在 `package.json` 和锁文件中。工作台嵌入原生 Agent、Session、工具注册与 AgentLoop，不复制上游聊天界面。

每次任务只读当前配置：

- ChatGPT：CC Switch 当前 Codex 提供商。密钥和端点来自同一提供商快照；当前 Codex 模型偏好仅在端点匹配时使用。
- Claude：当前 `~/.claude/settings.json`。明确设置的 `ANTHROPIC_AUTH_TOKEN` 优先于 `ANTHROPIC_API_KEY`，空 token 不会触发另一凭据的兜底。
- Qwen：本机全局 `~/.codex/tools/qwen/config.json` 与 `Load-Qwen.ps1`。每次创作都重新加载当前 Windows 用户的 DPAPI 加密密钥，再启动模型子进程；不把密钥复制进工程。文字与公式默认 `qwen-plus`，带图片时默认 `qwen3-vl-plus`，接入官方 DashScope 的理解与工具调用能力。

本项目不写 CC Switch、Codex 或 Claude 的全局设置。密钥留在服务端和受控子进程环境中，不放入浏览器、命令参数、模型提示词或公开错误。切换提供商后，下一个任务读取新配置；已开始的任务保持原连接。

Qwen 模型可在项目 `.env` 中用 `VISUALIZATION_QWEN_MODEL` 和 `VISUALIZATION_QWEN_VISION_MODEL` 分别指定。可选 `VISUALIZATION_QWEN_BASE_URL` 仅接受官方区域地址，须与账号区域匹配；Windows 保持 DPAPI 加载，Linux 服务器读取原私有 `.env` 的 `ALIYUN_KEY` 或 `DASHSCOPE_API_KEY`。页面的配置状态不是一次生成成功的保证。此次接入的是可视化创作模型，没有添加 Qwen-Image 生图功能。

可把 `.env.example` 复制为 `.env` 设置本项目选项：

| 配置 | 默认值 | 含义 |
|---|---:|---|
| `VISUALIZE_PORT` | `3088` | 本地服务端口，启动参数 `-Port` 优先 |
| `VISUALIZE_DAILY_CALLS` | `30` | 每个 UTC 日的模型步骤预留总额 |
| `VISUALIZE_DATA` | 本工程 `data/` | 任务数据库、上传素材与导出文件目录 |
| `PUBLIC_SITE_URL` | 空 | 正式 HTTPS 域名根地址；为空时只允许本机并禁止搜索索引 |
| `GITHUB_CLIENT_ID` / `GITHUB_CLIENT_SECRET` | 空 | GitHub OAuth App；密钥只在服务端配置 |
| `PUBLIC_ACCOUNT_DAILY_TASKS` | `3` | 公网每个登录账户每日真实创作任务上限 |

每次真实模型任务保守预留 3 次步骤调用，失败也计入；默认额度因此允许最多 10 个完整预留任务。本地案例、参数重算和导出不调用模型。DSH 审计与启动器状态仍保存在本工程 `data/` 下。

需要独立连接时，可使用 `VISUALIZATION_CHATGPT_MODEL`、`VISUALIZATION_CHATGPT_BASE_URL`、`VISUALIZATION_CHATGPT_API_KEY`，三项必须同时配置。Claude 使用相同名称中的 `CLAUDE` 前缀。协议、认证方式和配置优先级见 [runtime/README.md](../runtime/README.md)。`.env` 已忽略版本控制，不应提交真实密钥。

## 可以做什么

- 顶部「我的空间」集中学习资料、错题本、教案课包、设置、探索足迹与版本动态；「帮助」和首页提示可重播七步新手教程。设置支持系统/浅色/深色、减少动效、默认输入、自动播放、播放倍速以及悬浮球大小、透明度和位置，并按当前空间保存。
- 三维知识图谱可以旋转、缩放、检索与逐站浏览。路线使用真实关系，公式标签支持 LaTeX；不支持 WebGL 时可用二维关系图，关闭后释放图形资源。
- 画面下方可收藏作品、加入稍后看、记录时间点笔记或加入错题本。错题支持条件、答案、标签、复习记录和到期计划；教案课包可组合项目、公式、示例和笔记，排序并导出可阅读的文字快照。
- 「手写」提供画笔、橡皮、撤销重做与清空，完成后作为 PNG 带入图片创作。草图在当前页面暂存，关闭重开可继续，刷新会清除；不会自动调用识别或生成服务。
- 点击搜索入口或按 Ctrl / ⌘ K 可统一查找功能、作品、公式、学习资料与课包，只返回当前空间可访问的内容。设置冲突、保存失败和迟到请求均有对应处理，防止覆盖更新的输入。
- 从顶部或悬浮球进入公式库、知识图谱和帮助。悬浮球汇总现有任务，显示实际阶段、已知进度、取消和结果入口，不额外创建任务或轮询。拖动可改变位置，窗口缩小时自动约束在屏幕内。
- 公式库提供16条常用公式，支持 LaTeX 预览、搜索、笔记、标签、收藏、归档恢复，以及关联现有作品。可直接收录场景中的公式，或带回输入区继续创作；带入内容不会自动调用模型，也不会清空原输入。
- 知识图谱连接功能、主题、公式、示例和自己的作品。节点可直接打开对应内容，上一站和关联节点来自实际连线。图谱只读取项目摘要，最多展示最近64个项目；更早作品仍可从项目列表打开。
- 解释文字中的对象与关系；生成通用 2D/3D 图层、路径和关键帧。
- 绘制安全数学表达式、展示公式及下一式、标注上传图片。
- 用可信 Python 构建器计算函数、抛体、阻尼单摆、行波和旋转速度场，调整参数后重新计算。
- 通过积分面积逼近、光的折射与全反射、排队与服务过程三个新方案做参数实验。每个方案明确计算模型、单位和适用条件；本地示例可按数学、科学、三维、系统过程筛选。
- 按内容自动选择表现方式：空间与机械结构优先 Three.js 三维，公式变形优先 Manim，流程、图片标注及数值曲线使用二维画布；明确提出二维或三维要求时优先遵循。
- 通过实体构件展示风机与电机。风机支持叶片安装角、整体转子旋转、护罩分解及轴向气流示意；其他三维主题使用通用场景结构。
- 播放、暂停、拖动时间轴、调整播放速度、选择和隐藏图层，保存项目并继续描述修改。
- 同一个项目可以不断修改：勾选“在当前项目中继续修改”，成功后保留项目位置并生成新版本。点击“版本”回看任意旧版，或将它恢复为一个新版本；失败、取消或需要补充说明时保留原作品。
- 在三维画布中拖动旋转视角、滚轮或双指缩放，并随时复位。生成的内容可自行定义有边界的滑块、开关与构件拖动；例如主动轮带动从动轮反向转动、关节角度与构件拆解。
- “交互探索”即时响应并自动保存当前自由度和观察视角；“参数实验”仍由可信构建器重算物理结果，不会任意拖动后冒充数值计算。交互操作与保存不调用模型。
- 导出 Scene JSON，或使用本地渲染器导出 1280×720、15/24 fps 的 MP4。

生成时长可选 12、20、30 秒。图片接受 PNG/JPEG/WebP，上传不超过 5 MB、1200 万像素；服务端会去除元数据并缩放为最长边 1600 像素的 PNG。

“万物可视化”在这里表示可扩展的解释画布，并非任意工程求解器。通用场景是示意图，不会被标为已验证的数值仿真。单张图片不提供可靠的真实尺寸或完整三维重建；公式展示不等同于自动证明。输入模糊或缺少关键条件时，模型应提出澄清问题。

## 视频导出

浏览器导出需要 FFmpeg 在 PATH 中，并具备可用的 Chrome/Edge 或 Playwright Chromium。若没有浏览器：

```powershell
.venv/Scripts/python.exe -m playwright install chromium
ffmpeg -version
```

浏览器导出与交互预览使用同一场景引擎和绝对时间采样，支持 2D 与 3D。浏览器使用单独的无头配置，不读取个人浏览器会话。

导出前会等待交互状态保存，视频包含当前构件调整与观察视角；图层列表里的临时隐藏用于查看，不写入视频。页面导出的 JSON 包含原始可交互场景与当前探索状态。复位会恢复初始自由度与自动镜头，不会删除作品。

Manim 是可选后端，用于二维几何与数学公式变形：

```powershell
.venv/Scripts/python.exe -m pip install -r requirements-manim.txt
```

Manim 还需要本机可用的 FFmpeg、LaTeX 和 dvisvgm。三维场景使用浏览器导出。页面根据实际依赖显示可用后端，不会静默换用另一个渲染器。所有导出只执行固定的受信任渲染代码，场景数据不会成为 Python/JavaScript 程序。

Manim 使用 `TransformMatchingTex` 做公式对应变形，并同步图元的绝对时间关键帧。公式仅接受数学指令白名单，编译关闭 shell escape；中文说明放在文字图层。基础字体使用 Windows 微软雅黑或 Linux Noto Sans CJK SC。

## 执行与数据边界

单个模型任务最多 3 次模型请求、每步 8192 个输出 token、8 次受控工具执行和 120 秒总时限。只注册 `select_visual_tool` 与 `check_proposal` 两个受控工具，没有 shell、任意文件访问、MCP 或任意代码执行。模型先按语义提出选型，再生成场景，检查和最终输出均须与选型一致；机械三维场景必须有可见实体与运动。没有网络自动重试或提供商自动切换。局部推理强度最高为 low，不修改用户偏好。

右侧场景面板显示选用工具及理由。Manim 公式场景在网页中使用二维预览，导出时使用 Manim；三维预览和视频导出都使用 Three.js。旧作品保留原场景与历史，不会自动改成三维；可在当前项目中描述希望改变的表现方式。模型需要明确选择重建，才能切换方案或替换整个场景。

已有风机和电机案例可直接使用新增交互。其他历史自定义作品保留原内容；希望添加新的操作时，在当前项目中描述希望研究的关系，也可选中图层后点击“继续修改这个对象”。自由度由有界数据绑定实现，不运行模型生成的 JavaScript/Python；静态公式或图片没有合理的连续变量时，不会硬加无意义的移动控件。交互协议见 [docs/interaction-contract.md](interaction-contract.md)。

普通改稿只合并明确改动的对象和字段，未涉及的轨迹、关键帧、交互及步骤使用本机保存的完整数据。提供给模型的精简上下文不会取代原始数据。没有重新上传图片时沿用当前项目素材；重算、生成和恢复都检查版本，避免旧页面或迟到任务覆盖新成果。历史预览可以播放和观察，恢复后才能继续保存或导出。

新方案的范围：积分示例计算固定函数 `y=x²` 的黎曼和并与解析面积比较；折射示例采用单平面界面的几何光学，不计算光强或偏振；排队示例采用固定到达、固定服务、先到先服务的单服务台模型。它们可以准确解释对应规律，超出这些假设的内容由模型选择其他方案或先请求补充条件。

原生会话事件的脱敏审计副本位于 `data/dsh-home/audit/`，记录工具结果、步骤和终态，去除凭据、图片 base64 和原始上游错误。它不用于自动重放。正常项目数据默认保存在 `data/workbench.sqlite3`、`data/assets/` 和 `data/media/`；缓存与导出中间文件位于项目临时目录。

默认只允许本机访问；设置 `PUBLIC_SITE_URL` 后，服务只额外接受该正式域名，仍监听 `127.0.0.1`，由 HTTPS 反向代理提供公网入口。写操作校验来源与 CSRF；项目、素材和公式按服务端会话或账户隔离，不列入公开页面与站点地图。本机保留同一浏览器会话即可在重启后查看历史作品。备份时先停止服务，再复制项目数据目录；不必复制 `.venv` 或 `node_modules`。

公式也按同一会话保存，每个会话最多200条（含归档）。公式库“导出”包含可再次导入的 JSON；“导入”支持本格式、公式数组或旧站的 `formulas` 数组（基础 `latex`、`note`、`title`、`tags` 字段）。重复内容跳过，整批验证失败不会部分写入。旧站账户、验证码、会员权限和完整题解不会被当成公式导入。关联项目必须属于当前会话；跨浏览器迁移时可先移除文件中的 `project_id`，公式和笔记仍可独立保存。

## 公网介绍、登录与检索

本机 GitHub 登录配置可双击根目录 **`配置GitHub登录.cmd`**，以隐藏输入填写 Client Secret；已有 Client ID 可回车保留。配置只写本工程 `.env`，完成后重启服务。操作说明见 [本机 GitHub 配置](github-local-setup.md)，也可从网页账号菜单打开。真实登录仍需 GitHub 应用和用户授权，不会把未配置状态显示为登录成功。

`/about` 介绍产品用途和数据去向；`/explore` 提供 12 个无需运行 JavaScript 即可阅读的示例说明，并链接到工作台对应示例。公开介绍不读取个人项目或上传文件。已有项目、公式、素材、任务和导出文件仍通过权限校验访问。

`PUBLIC_SITE_URL` 必须为正式 HTTPS 域名根地址，不接受 IP、非标准端口、路径、查询或片段。首页与介绍页的 canonical、Open Graph、Twitter 和 JSON-LD 均从该配置生成，不从请求 Host 或转发头推导。本机默认 `noindex`、robots 全站禁止抓取且 sitemap 为空；启用正式域名后仅首页、产品介绍与示例介绍进入 sitemap。分享卡片为工程内已有标志生成的本地 SVG/PNG，无外部图片服务依赖。

公网访客可匿名探索内置示例，最多保留 24 个访客项目；自行创作、上传图片和视频导出需要邮箱或 GitHub 登录。邮箱入口支持旧用户名/邮箱密码、验证码注册、绑定验证和找回密码。旧 MySQL 的账号、bcrypt 密码与会员角色可直接沿用，见 [旧账号与资料接入](legacy-accounts.md)。GitHub 只请求最小公开身份信息，不请求邮箱或仓库权限，也不会按同名自动合并旧账号。

默认创作模型为 Qwen。普通在线用户只能使用 Qwen；VIP、管理员及直接访问本机工作台的用户可选择已配置的 ChatGPT/Claude。权限在服务端检查，不能靠修改网页绕过。公网配置会关闭本机例外，避免反向代理误判。VIP/管理员免个人额度，但保留全站预算保护。真实模型任务会把本次文字、公式和图片输入发送给对应提供商；公开部署后的项目数据保存在站点服务端。

公网保护同时包含账户任务额度、全站模型步骤预算和昂贵请求限速。应用对 `POST /api/jobs`、`POST /api/assets` 与项目视频导出按直连对端每分钟最多 60 次限速，不限制阅读、取消、保存或参数调整。反向代理与应用在同一机器时，应用看到的是同一个代理 IP，因此该值相当于代理入口的合计限额；部署说明另提供代理端按真实连接 IP 限速的示例。

配置、GitHub 回调、HTTPS、日志脱敏、robots 验证和站长平台提交步骤见 [docs/deployment.md](deployment.md)。这些配置使公开页面具备抓取条件，不保证搜索引擎收录或排名；本次工程准备不会自动部署或提交任何现有公网站点。
