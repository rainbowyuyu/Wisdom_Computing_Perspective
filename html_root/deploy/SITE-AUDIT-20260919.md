# 知识图谱与页面检查 · 2026-09-19

本次在原站风格上补齐功能入口，并检查静态版（8000）和 Vue 版（5173）。所有发布文件仍位于 `html_root`。

## 图谱补全

新增 15 个节点及其关联边。目前共 103 个节点、164 条有向连接；全部节点可从中心节点到达，没有重复 ID、重复连接或悬空连接。主页 3D 图谱、图谱搜索及星云车站继续共用 `static/js/site-graph.js`。

| 功能 | 新增入口与实际行为 |
| --- | --- |
| 账户 | 账户与额度、联系作者开通 VIP、管理员用户管理；游客不能通过图谱绕过权限 |
| 星云 | 展开悬浮窗查看进度与成就，继续访问后台任务 |
| 智能体 | 后台任务面板、复杂题拆解；切换拆解模式保留输入，不自动提交题目 |
| 动态计算 | 可视化公式输入、导出笔记、复制解答、题解加入错题本、题解加入课包 |
| 典型例题 | 例题总入口、高中例题、大学例题；直接切换教学案例筛选 |
| 帮助 | 分步解题指南 |

例题、输入题目、分步推导、完整题解以及保存、动画、错题、课包入口现已纳入同一图谱；另外加入“复杂题拆解 → 后台任务 → 阅读结果/查看进度”的连接。结果相关操作先定位真实控件并展开“更多”；尚无题解时回到输入区域提示用户。

## 本次发现并修复的问题

- Vue `/home` 未匹配路由造成空页：重定向到首页。
- Vue 设置入口只是日志占位：按需加载原站设置、账户资料及账户安全弹窗，复用原有本地和账户存储。
- Vue 新手引导未接入：两套入口共用六步引导，覆盖账户、例题、计算、后台任务、算式库、星云；不自动提交计算。
- Vue 悬浮球缺少球体容器：补齐原样式，并让水波进度位于球内。
- 导入课包在深色模式下使用白底且无法通过键盘直接激活：使用主题色和原生按钮，可按 Enter 打开文件选择器。
- 图谱“立即识别”指向不存在的按钮，画笔/橡皮等入口未正确定位：对齐静态版和 Vue 版的真实控件。
- 更新日志、API 文档节点仅跳到帮助页：改为打开对应文档。
- 游客打开受限课件失败后仍被标记为当前站：失败时不更新车站状态。
- 最近练习的名称、关键词及图标不一致：改为历史练习含义。
- 图谱初始视角下标签过淡：按相机距离调整标签透明度，选中节点保持清晰。
