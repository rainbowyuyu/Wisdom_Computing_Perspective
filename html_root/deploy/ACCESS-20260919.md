# 账户权限实施与检查

- 高风险：前端自行标记 VIP 或管理员会造成越权。已将角色绑定到 MySQL `users.id`，每个管理请求重新校验服务端角色，公开注册与资料修改不能设置角色。
- 高风险：游客换页面或并发提交绕过试用。已统一拦截计算、识图、助手、创作及动画入口，MySQL 原子行锁计数；浏览器标识和 IP 哈希都检查，刷新 Cookie 不单独恢复试用。
- 高风险：管理员固定密码进入代码或 SQL。提供服务器交互授权脚本，验证已有 bcrypt 密码后授予权限，源码、SQL 和管理响应均不包含密码或散列。
- 中风险：取消 VIP、停用用户后旧会话继续使用。每次 API 和模型调用重新读取权限，管理变更无需退出后再登录。已发出的上游请求不能保证撤销计费。
- 中风险：VIP 去掉次数限制后占满资源。个人日次数免限，全站模型成本、调用速率、输入输出长度、并发和渲染队列保护继续有效。
- 中风险：跨站管理请求与管理输入注入。继续使用 Origin 校验；管理 SQL 参数化，邮箱格式校验，页面用户信息转义，无密码字段返回。

验证涵盖真实 MySQL 并发试用、普通日额度、日切换、授予/取消 VIP、停用、管理越权、自身降权保护、全站成本保护和单文件 SQL 重复执行。静态与 Vue 页面检查主页身份、管理交互、移动布局及试用结束登录提示。此记录针对本次权限变更，不是完整渗透测试。

限制：无登录身份无法可靠识别同一自然人。共享 IP 可能共享游客试用；同时更换网络与浏览器身份仍可能重复试用。VIP 不免服务商限额或服务停机。部署仍为单进程，登录会话在重启后失效，权限与额度不会重置。

## 账户展示与独立管理页

- 桌面右上角、手机导航栏显示当前身份和剩余额度；游客显示计算试用，普通用户显示每日剩余 / 总量，VIP 和管理员显示额度不限。失败状态提供重试，不将缺失数据解释为无限额度。
- 首页和额度用尽提示中的“联系作者”前往 `https://github.com/rainbowyuyu`，新标签打开。邮箱保留为备用设置。
- 管理员从右上角“管理”、首页“用户管理”或知识图谱进入独立页面：静态入口 `/?section=admin`，Vue 入口 `/admin`。
- 管理页复用 `/api/admin/*`，支持搜索、分页、授予/取消 VIP、个人与默认日额度、账户停用、重置今日用量和管理记录。个人额度留空跟随默认值，0 表示无每日额度；VIP 不受个人日额度限制。
- 切换账户、离开页面时取消未完成的管理请求；无管理权限时不加载用户列表，收到 401/403 时清空用户和管理记录。后端权限校验保持有效。
- 验证：两套入口共 6 项账户浏览器测试、4 项知识图谱浏览器回归、6 项图谱数据测试，以及隔离账户的真实 MySQL 权限测试。桌面 / 手机、明暗主题截图检查通过，Vue 生产构建通过。


## 请求记录与主账号权限收紧

管理后台、请求明细、管理审计及角色调整仅允许 `rainbow_yu` 且角色为 `admin`。它可将其他账户设为普通用户、VIP 或管理员，也可撤销这些身份；主账号自身不能降权、停用或更名。其他管理员身份保留个人不限额度，但不开放管理后台或任意 Python 渲染。前端使用服务端 `can_manage` 能力字段隐藏入口，后端独立校验。

新增请求记录表及异步写入模块，读取接口分页、限时范围并禁止缓存。只选取业务题目字段，常见凭据脱敏，不采集上传图片和脚本原文。JSON 业务错误和 SSE error 均标为失败；后台任务生命周期同步到请求记录。写入故障不会阻塞主流程，管理页可看到写入异常提示。静态与 Vue 管理页面共用筛选、详情与安全文本/公式渲染。


## 权益说明与帮助入口

导航栏身份 / 额度胶囊打开账户权益面板，展示当前余量、可用能力、服务限制及申请步骤。主账号另有直接进入管理中心的按钮；首页与帮助页也提供入口。申请说明可复制并前往 GitHub 联系作者，不代替用户发送消息或自动开通。角色变化会关闭旧账户说明，数据读取失败仅展示重试。

静态和 Vue 帮助页统一使用 `static/js/help-center.js` 的问答与搜索，包含权益、VIP、主账号管理、题目记录、复杂题、动画修复、课包及隐私说明，避免两套前端帮助内容不同步。
