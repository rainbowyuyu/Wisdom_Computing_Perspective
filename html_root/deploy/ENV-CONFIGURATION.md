# 环境配置说明

配置放在 `main.py` 同目录。`.env` 保存网站通用配置；`.env.local` 只写该机器需要覆盖的项目，例如本地与服务器不同的模型密钥或数据库连接。无需在两份文件中重复全部设置。

优先级为 **系统/宝塔环境变量 > `.env.local` > `.env` > 程序默认值**。如果修改 `.env` 没有生效，先检查前两处是否设置了同名项。空值也会覆盖低优先级配置；想恢复继承，应删除或注释这一行。修改后重启网站自己的 `main.py` 项目。

## 主要分组

| 分组 | 用途 |
| --- | --- |
| 启动与代理 | 监听地址、端口、正式网站来源及可信反向代理 |
| MySQL | 网站数据库地址与账号，沿用宝塔中的已有值 |
| 大模型 | 阿里云密钥、解题模型、全站调用预算和并发 |
| 资源保护 | 入口限流、内存/磁盘保护、数学与动画子进程上限 |
| 企业邮箱 | SMTP 发信账号、授权码、验证码时效与限额 |
| 视频与 CDN | 视频签名密钥和可选 CDN；默认使用本站视频 |

普通用户每日额度、VIP 和管理员身份在管理员面板设置，不需要另造 `.env` 参数。`AI_GLOBAL_DAILY_CALLS` 等是全站费用保护，VIP 也不绕过服务总预算。模型调用次数包括自动修复；日预算按 UTC 日期结算，token 额度使用保守预留。

小型宝塔服务器建议先保持数学与 Manim 各一个运行任务。并发模型调用不会增加本地渲染槽位；不要同时启动多个 `main.py` 实例或开启多 worker。Linux 内存限制按单进程地址空间执行，不能代替网站独立服务的总内存限制。

## 邮箱与密钥

腾讯企业邮箱使用 `smtp.exmail.qq.com`。端口 465 对应隐式 TLS，587 对应 STARTTLS，均保持 `SMTP_USE_TLS=1`。发信账号及 `SMTP_FROM` 使用 `noreply@wiscomper.cn`，授权码填写到 `SMTP_PASSWORD`。填写配置并不自动证明邮箱服务商已允许发信。

`EMAIL_CODE_SECRET` 与 `VIDEO_TOKEN_SECRET` 使用两份独立随机值；可分别运行以下命令生成，结果只写入该环境的私有配置：

```sh
python -c "import secrets; print(secrets.token_hex(32))"
```

更换验证码密钥会使未使用验证码失效，更换视频密钥会使旧签名链接失效；重新获取链接即可。已有有效密钥无需每次部署重新生成。

## 部署时怎么用

- 已有服务器：继续保留服务器的 `.env`、`.env.local`。本次分组优化不要求用本机的密钥覆盖服务器，也不要求执行 SQL。
- 新环境：参照 `.env.example`，填写数据库、模型、邮箱及两份随机密钥；模板中的空白和占位值不能直接当作生产凭据。
- 默认 `HOST=127.0.0.1` 同时适合本地和宝塔 Nginx 反代；Nginx 上游端口应与 `PORT` 一致。不需要为了反代将服务暴露到所有网卡。
- 值中有空格或 `#` 时加引号；文件使用 UTF-8。不要把 `.env` / `.env.local` 放进 Git 或通用部署压缩包。
- `USAGE_DB_PATH` 和 `MATH_TASK_DB_PATH` 通常留在注释中。不要取消注释后留空，以免运行记录路径错误。

`.env.example` 仅列出程序实际读取的配置；CDN 资源包编号不会参与网站请求处理，无需填写。
