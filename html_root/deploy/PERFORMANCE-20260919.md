# 2026-09-19 页面速度与任务进度优化

已部署到本地 `main.py` 服务。保留现有页面与悬浮球风格，静态入口和 Vue 入口共用任务状态。

| 调整 | 影响 / 工作量 | 验证 |
| --- | --- | --- |
| 3D 图谱依赖改为进入可视区域才加载，复用单例，失败支持重试 | 高 / 中 | 计算页原先请求 Three.js 和 ForceGraph 两个库，现为零；进入主页并滚动到图谱后加载两项并成功生成 canvas，离开页面暂停 |
| MathLive 异步加载，输入先可用，组件就绪后接入 | 高 / 小 | 拦住 MathLive 请求不返回时，两套前端仍能完成 DOM 初始化、输入题目；键盘初始化由轮询改为等待组件定义 |
| HTML、JS、CSS、SVG、Markdown 文本压缩 | 高 / 小 | 首页 HTML 133,619 → 29,341 字节；main.js 28,684 → 9,356 字节；星云 CSS 41,406 → 7,981 字节（修改时同一源码、本机 HTTP 原始响应体测量） |
| 星云统计读取汇总计数 | 高 / 中 | 原四个内容列表请求合为 `/api/user/stats` 一个查询响应，只含四个计数；按会话身份读取，响应小于 200 字节，不能用 username 参数读取他人数据 |
| 统计请求合并与缓存 | 中 / 小 | 同账户复用正在进行的请求，缓存 30 秒；登录变化、算式/错题等变更失效，旧请求不会覆盖新账户缓存 |
| 减少无效初始化和序列化 | 中 / 小 | 删除重复开发者工作台初始化，账户卡片 DOM 观察按帧合并；尚未保存题解时跳过用于比较保存版本的完整题解 JSON 序列化 |

SSE/API 和视频不进入静态压缩中间件，避免流式进度被缓冲以及重复压缩媒体。宝塔若已经由 Nginx 压缩响应，应检查最终响应头；不要给事件流启用代理缓冲。

悬浮球复用水位与海浪视觉：有真实步骤数时显示百分比，排队、模型推导、识别和自动修复等未知总量阶段显示持续流动的等待态，不根据经过时间伪造完成率。多任务状态按请求隔离，一个完成不会覆盖仍在运行的其他任务；后台任务通过既有轮询同步，不增加模型调用。展开后可以查看各任务状态、返回对应页面，前台生成任务可停止。结束、取消和失败都会收尾，账户切换清除旧任务显示。

海浪使用变换动画；页面隐藏或悬浮窗展开时暂停球内动画，尊重减少动态效果设置，支持深色模式、移动端和键盘打开。前台进度来自原响应流，不额外克隆整条 SSE 响应，也不会重复提交任务。

验证：13 项 JavaScript 进度/流式测试通过；新增与扩展的 5 项浏览器检查覆盖两个入口的海浪、多任务、跨页、取消、移动端深色/减少动态效果、图谱按需加载和 MathLive 慢加载。另有 7 项既有浏览器回归（解题恢复、账户提示、后台任务）通过；静态压缩、真实 MySQL 汇总隔离检查通过；Vue 构建通过。测试不调用真实付费模型。

页面总请求数不作为单独的提速指标：新增了轻量任务进度模块，但移除了计算页的大型图谱库。外部 CDN 会影响导航时间；采样曾发现 MathLive 约 6 秒的外部等待，已经解除它对页面初始化的阻塞。本轮未作公网压力测试或宣称特定的全站加载耗时百分比。

后续按优先级建议：

1. 中影响、中工作量：结合实际部署地区，将仍依赖 CDN 的字体及通用库做版本固定和可靠托管，测量公网冷启动的 LCP/INP。
2. 中影响、中工作量：用实际账户数据规模和预期并发压测统计与列表接口，依据慢查询结果决定进一步分页和索引调整。
