## 本次累计更新

1. **运行稳定性**：数学计算改用可终止的独立进程；Manim 共用有上限的渲染资源，超时、取消和异常后回收子进程。检查内存和磁盘空间，资源不足暂停新重任务，后台题目等待资源恢复；正常浏览与取消入口保持可用。
2. **安全与账户保护**：成就按登录账户授权；改密撤销旧会话；换绑邮箱增加当前密码校验；头像经过解码、尺寸限制与重编码；对外隐藏内部异常细节。
3. **网页与连接保护**：本地 DOMPurify 清理富文本，外部脚本固定版本并补充完整性校验；API/WebSocket 增加入口限制和连接清理；补充安全响应头与私有响应缓存策略；升级 Python 安全依赖。
4. **响应速度与体验**：调整阻塞数据库调用的执行方式，降低对其他请求的影响；保留视频流缓存与 Range；识别等待可见、可取消，避免重复点击和旧结果覆盖新输入。
5. **识别到解题**：统一图片识别和智能体识图，保留完整题干、公式和图形标注。无效图片提前拒绝，识别失败保留原图，可裁剪、重试、手动补充。模糊内容先核对，计算以完整题面为准；修复新版手写画板导出。
6. **一次一道题**：去掉多题并发引导，同一用户最多一道活跃后台题；保留同题小问、选项与方程组，不同账户仍可并发。更新帮助、知识图谱和相关页面提示。

## 一次部署步骤（宝塔）

1. 备份现有网站目录和数据库，保留网站当前 Python 环境的依赖记录。停止宝塔里**智算视界自己的 Python 项目**，不要停止宝塔面板服务。
2. 将压缩包解压到临时目录，再将包内 `html_root/` 的全部内容覆盖到服务器中现有 `main.py` 所在目录。例如：包中 `html_root/app/recognition.py` 对应网站根目录的 `app/recognition.py`。不要变成网站根目录下再套一层 `html_root/`。
3. 在网站根目录，使用宝塔该网站项目的 Python 环境执行：

   ```sh
   python -m pip install -r requirements.txt
   python -m pip check
   ```

   上面的 `python` 必须是网站项目的解释器/虚拟环境，不能是宝塔面板自己的 Python。依赖安装报错时先处理兼容性，不要跳过安装直接上线。静态资源及 Vue 产物已包含，不需要在服务器运行 npm 构建。

4. 保持服务器自己的 `.env` 和 `.env.local`。**不要拿 `.env.example` 覆盖它们**；数据库、邮箱、模型密钥和域名配置继续沿用。新增保护参数都有默认值，无需填密钥或额外配置即可启用。
5. **本次无需执行 SQL**，没有新增 MySQL 表；运行记录由应用维护，保留 `var/`。本包没有需要手动删除的源码文件。
6. 使用原宝塔项目配置启动，入口仍为 `main.py`，等效命令为 `python main.py`。保持一个进程，不启用多 worker 或 reload。不要另外启动第二个实例占用相同端口。
7. 刷新页面并重新登录（重启可能使旧会话失效）。验证健康接口、登录、一道清晰图片的识别核对，以及一个简单题目的分步计算和动画：

   ```sh
   curl --max-time 5 http://127.0.0.1:8000/healthz
   ```

   应返回 `{"status":"ok"}`。若项目端口不是 8000，替换为现有配置端口。健康接口只确认网页进程可响应，邮箱与模型仍需各自的功能检查。

## 保留的数据与配置

- 压缩包不包含 `.env`、`.env.local`、数据库文件、运行日志、用户头像、用户生成视频或其他上传数据；覆盖部署不会主动删除这些内容。
- `.env.example` 是配置参考，包内测试使用模拟数据；无需在服务器运行测试。
- 保留数据库和现有文件即可；若部署验证失败，恢复备份源码及原依赖环境，不删除用户数据。
- 资源保护降低崩溃风险，不能替代整机监控。该服务器此前多个服务共用有限内存，后续应给网站配置独立的服务资源上限，不能直接限制整个 `bt.service`。
