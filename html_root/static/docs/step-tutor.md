# 分步解题与可视化

在首页点击「开始分步解题」，输入题目后即可逐步查看推导、操作图形，并选择生成 Manim 动画。数学运算可视化页仅保留统一的分步解题流程，已移除旧公式编辑器与自由动画工作台。

## 如何使用

1. 输入文字题目或 LaTeX，点击「开始解题」。Ctrl / Command + Enter 也可提交。
2. 左侧选择步骤；拖动图形下方的滑块观察函数值、切线、累积面积或矩阵变换。
3. 「自动讲解」按顺序播放步骤并演示图形，可暂停和调整速度。
4. 勾选「同步生成动画」即可在解答完成后生成视频。视频章节与步骤互相联动，也可下载 MP4。
5. 在右侧智算星云中查看任务、停止或回到解答。切换页面不会中断任务。
6. 登录后点击「保存到我的算式」，将题目、上下文、完整步骤、交互图形数据与动画章节保存到当前账户。再次生成动画会更新同一条已保存记录。
7. 在「我的算式」点击题解卡片的「阅读题解」，可切换步骤、播放动画、复制解答、导出 Markdown 笔记，或「继续探索」回到可视化页。复制和导出也位于解题结果的「更多」中。
8. 最近 8 道题同时保留在当前浏览器的「最近练习」中，可手动清空；本机记录不等于账户保存。

## 算式库数据

网页的公式与含公式文字统一由 `static/js/math-text.js` 渲染。它在题解恢复、阅读、导出时兼容旧版因式分解的 `\quadx` 拼接错误，并处理整条公式的分隔符及重复转义，保留矩阵和多行公式的行分隔。数据库旧记录在读取时修正，无需删除记录或重新解题；无法识别的 LaTeX 保留源码并提示格式问题，不猜测数学含义。

题解沿用现有 `formulas` 记录与知识标签体系，结构化内容存入关联表 `formula_solutions`。表会在首次访问时自动创建，需要现有数据库账户具备建表权限。旧公式保持可用；删除题解会级联删除关联内容。新接口通过现有登录 Session 判定账户，不接受客户端指定拥有者。

- `POST /api/formulas/solutions`：保存 `{id?, problem, context, solution, video?}`，有 `id` 时更新属于当前账户的记录。
- `GET /api/formulas/solutions/{id}`：读取完整题解与视频章节。
- `DELETE /api/formulas/solutions/{id}`：删除当前账户的题解。
- `GET /api/formulas/list/me`：列出当前账户的公式与题解摘要；避免在列表加载全部图形点数据。

动画文件仍由现有 `/videos` 路径提供，数据库保存文件引用与章节信息。备份时需同时备份 MySQL 和 `static/videos`，以便恢复视频播放。

## 可直接体验的题目

- `解方程 x^2-5*x+6=0`
- `求导 sin(x)`
- `积分 x^2`
- `定积分 x^2 从 0 到 1`
- `矩阵 [[1,2],[0,1]]`
- `\begin{bmatrix}1 & 2 \\ 0 & 1\end{bmatrix}`

以上题型调用本地 SymPy：一元一次／二次方程、基础表达式求导、多项式不定积分与定积分、二维矩阵行列式和变换。带额外条件、证明题、复杂自然语言题目和图片识别使用配置的阿里云模型。题解下方说明计算或推导来源；AI 推导不会标记为已经符号验证。

## 图谱与悬浮窗

知识图谱支持搜索节点、点击导航、缩放、还原和全屏。图谱离开屏幕或切换到其它页面时会暂停；不支持 3D 时仍可使用搜索导航。

智算星云默认收起。点击或按 Enter / 空格展开，拖动小球或窗口标题移动，Esc 收起；聚焦标题后可用方向键移动。窗口位置会在缩小屏幕时自动限制在可见区域，并保存在本机。系统启用「减少动态效果」时会降低动画。

## 运行环境

在 `html_root` 安装 `requirements.txt`，使用 Python 3.12+（本次验证使用 3.14）、FastAPI、Pydantic 2、SymPy 和 Manim。渲染需要 FFmpeg；数学排版使用 LaTeX。不支持的命令、不完整的括号或 TeX 编译失败会停止本次视频生成并提示重试，保留已有交互解答，不将原始 LaTeX 字符串作为公式写进视频。中文字体优先使用 Microsoft YaHei。

启动后端：

```powershell
..\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000
```

静态站点位于 `http://127.0.0.1:8000/`。Vue 入口在 `vue_root` 运行 `npm run dev`，通过 Vite 代理使用同一个后端。Vue 构建只包含前端，部署时 `/static`、`/api`、`/videos` 等路径需交给 FastAPI，不能只上传 dist 而省略后端。

复杂题目与识别需要服务端配置 `ALIYUN_KEY`，并确保阿里云账户状态正常。个人密钥放在被 Git 忽略的 `html_root/.env.local`；加载优先级为进程环境变量、`.env.local`、`.env`。更新后需重启后端。`SOLVER_MODEL` 可选择推导模型，默认 `qwen-plus`。遇到欠费、鉴权失败或限流会显示实际原因；本地工具仍然可用。

## 接口

| 接口 | 用途 |
| --- | --- |
| `GET /api/solve/capabilities` | 已配置的工具能力（不代表远端账户可用） |
| `POST /api/solve/stream` | `{problem, context?}`，返回 status、plan、step、complete 或 error 的 SSE 事件 |
| `POST /api/solve/render` | `{solution}`，返回队列状态、实际章节进度和视频 URL |

AI 可以选择函数表达式；服务器用受限数学解析器和实际采样计算图形数据。Manim 执行固定场景程序，读取经过校验的数据。渲染最多同时运行 2 个任务，每个最长 240 秒；停止或断开连接会终止该任务的进程树。图形预览可在等待期间继续操作。

几何图使用 `points` / `labels` 定义点，`segments` 定义实际线段的点索引对，例如三角形边为 `[[0,1],[1,2],[2,0]]`。`segments=[]` 仅显示标记点；省略该字段兼容已有的折线数据。交互图与 Manim 共享连线定义，几何滑块与自动讲解逐渐展示线段。

## LaTeX 输入与连续动画

新题输入提供「题目 / LaTeX」和「可视化公式」两种方式，共用同一份草稿。文字模式保留完整条件并实时预览公式；可视化模式使用识别结果同款 MathLive，支持分数、根式、积分与矩阵编辑。切换模式、恢复历史和读取已保存题解都会同步内容。组件尚未加载时仍可通过文字输入解题。

步骤、提示、结论和「我的算式」阅读器统一使用安全的 KaTeX 排版，同时兼容旧记录中未加分隔符的 LaTeX。原始题目与题解仍存储在同一数据库记录中，复制和导出也使用这些数学表达式。

`\int_0^1 x^{2}+3x\,dx` 可直接由本地数学工具识别，精确得到 `11/6`；保留附加条件的复杂题面交给数学智能体。仅解析完整匹配的积分，不能把题目后面的条件当作多余文字丢弃。

Manim 每章保持 5 秒，继续兼容保存记录与章节跳转。公式使用 `TransformMatchingShapes` 在字形之间连续过渡；相同图形对象和坐标轴跨步骤保留。新曲线和几何辅助线使用 `Create` 逐渐画出，积分面积用逐帧累积呈现，导数在原函数上移动切线，矩阵将同一个单位正方形和基向量连续变换到目标位置。AI 只输出受限的数学和几何数据，不生成或执行 Python 场景代码。动画呈现题解中的数学关系，AI 推导仍需核对。

验证覆盖两个前端的输入切换、真实积分求解、裸 LaTeX 兼容阅读、移动端布局，以及方程、积分、导数、矩阵、逐步添加中线的几何视频。`node --test tests/math-text.test.mjs` 检查嵌套公式、矩阵换行、未完成输入和 HTML 字面量处理。

对智能体输出额外检查明确的标量矛盾：当摘要与最终等式描述同一变量或长度时，比较数字与数值分数；不一致会自动要求模型重试一次，仍冲突则不发布该题解。这只是有限的一致性检查，不会把 AI 推导升级为符号验证。

## 智能体与代码助手

智能体页统一为输入、对话、执行进度和结果入口。支持粘贴或上传题目图片，也可直接输入数学题和动画需求。它先确认登录账户，再按计划依次等待识别、解题、动画、保存等工具的实际结果；失败会停止后续步骤并提供重试，停止只取消当前任务。页面切换后可通过底部任务条返回。Enter 发送行为沿用设置中的偏好，关闭后使用 Ctrl / ⌘ + Enter 发送。

题解保存到「我的算式」后可阅读分步公式、播放动画、复制及导出笔记。成功的智能体流程可存为模板。动画脚本和模板均保存在数据库，服务端验证当前登录账户的归属。

开发者工具采用编辑器、预览、代码助手的布局，在手机上依次排列。代码助手读取完整脚本和最近运行日志，支持从零创作、修复报错、改善动画；建议先显示完整代码差异，用户可预览实际画面、应用修改、应用并运行或放弃。应用时检查脚本是否被手动修改，避免覆盖新编辑；应用后可以撤销。停止生成不覆盖工作台代码。切换 Vue 页面保留代码草稿并正确释放编辑器。

生成接口仅声称已通过语法检查；关键帧和视频分别由真实 Manim 渲染后显示成功。运行失败可将日志交给助手修复。支持一个自定义名称的 Scene，运行器保留源代码并提供兼容入口。开发者代码运行与题解的固定数据场景不同，当前导入与语法限制不构成完整的代码执行沙箱。
