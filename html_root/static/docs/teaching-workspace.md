# 教案、课包与课堂播放器

## 备课与保存

登录后进入「教学案例」，点击「创建课包与教案」。填写课程名称、适用对象、课时、教学目标、重难点、准备、教学过程、练习与反思；文字中可以使用 `$...$`、`$$...$$` 编写 LaTeX。可先填入教案结构，再按实际教学内容编辑和预览。

从案例目录选择视频，调整上下顺序后保存。课包与教案存入当前账户的数据库，可在「我的课件」重新阅读、编辑、播放或删除。删除课包不删除原视频；不同账户之间的课包和笔记互不可见。多窗口编辑发生版本冲突时，保留当前输入并提示重新读取，避免覆盖已保存修改。

可导出 Markdown 教案或 JSON 课包；通过「导入课包」将本站格式的 JSON 保存为新课包。JSON 包含教案和案例视频引用，不包含离线视频文件，播放需要连接本站，导入时引用的视频必须仍存在于本站案例目录。

## 播放与学习

从课包打开视频后，可直接选择上一节、下一节或阅读教案。播放进度在播放期间和关闭时保存，重新打开时继续观看。观看覆盖率只统计本次实际播放的片段，拖动进度不会增加覆盖率。

播放器采用主画面与右侧选集的双栏布局，小屏自动改为单栏。右侧可直接切换选集、笔记、弹幕、教案与课包、评论；支持宽屏模式、全屏、倍速、音量、拖动进度条及键盘操作。课包勾选「自动连播」后会在本节结束时播放下一节，最后一节停止；默认关闭自动连播。

视频下方的「创建课包」会暂停当前视频、预填课程名称并选中该视频。补充教案或更多视频后保存，即可从「我的课件」重读；课包阅读页的「开始上课」按保存的顺序播放。

弹幕支持颜色、滚动、顶部和底部位置，发送后写入数据库并实时推送给同一视频的在线观众。弹幕按视频时间显示，暂停、倍速和跳转保持同步；密集弹幕按可用轨道排布。播放器的「弹幕」页签可查看保存的内容、跳转时间点和删除自己发送的弹幕。

「笔记」支持时间点记录、LaTeX 阅读、点击回放与删除；也可将笔记带入智能体生成练习。「教案与课包」可为当前视频新建教案或加入已有课包。视频分享链接包含当前时间点。

## 主页与智能体入口

在主页知识图谱搜索「教案」「我的课件」「弹幕」等词，查看功能介绍及前后关联，点击「打开此功能」执行对应操作。教师推荐路径连接「编写教案 → 挑选案例 → 我的课件」。图谱不可用时仍可通过搜索和关联按钮导航。

智能体支持「打开教案」「创建课包」「打开我的课件」「打开播放器弹幕」「打开时间戳笔记」。这些指令打开真实编辑器或学习工具，教案内容由用户填写并保存。

## 开发验证

`WISDOM_DATABASE_TESTS=1 WISDOM_BROWSER_TESTS=1 python -m pytest tests/test_teaching.py -q`。

需要已配置的 MySQL、Chrome 及运行中的后端和 Vite。测试使用临时账户，覆盖课包 CRUD、顺序、版本冲突、账户隔离、WebSocket 弹幕、原版与 Vue 的保存重读、导入导出、播放器和图谱/智能体入口，结束后清理测试记录。


## 题解、错题与课包联动

- 在分步解题结果、我的算式题解阅读器、错题详情中点击“加入课包”，选择课包或新建课包。
- 课包“题解与练习”支持阅读快照、继续可视化解题、回到原题解或复习原错题、调整顺序与移除。收录快照不会随原题后续修改改变；删除原题后仍可阅读快照。
- 导出教案包含学习材料，导出和导入 JSON 包含完整题解快照。视频仍是本站引用；导入材料不关联其他账户的原记录。
- 顶部全站搜索可直达个人课包、错题和已保存题解。知识图谱中的“到期错题复习”和智能体指令“复习错题”进入同一套复习流程。
