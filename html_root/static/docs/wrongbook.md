# 错题本与复习

进入「教学案例 → 错题本」，或在主页知识图谱、智能体中打开错题本。

支持三种收录方式：手动填写；在视频的「笔记」页签保存当前时间点；在数学解题结果的「更多」或已保存题解中选择「加入错题本」。填写题目、正确思路、错因、知识点标签和难度后保存，内容属于当前登录账户。

题目、答案和错因支持 LaTeX。收录分步题解时会保留当时的步骤快照；即使之后删除原算式，也能阅读该快照。视频记录可直接回到原时间点，错题也可发送给智能体编写同类练习。

错题列表支持搜索、知识点和复习状态筛选、分页、编辑、删除及 JSON 导出。JSON 包含错题内容和复习历史。已有浏览器本地记录可点击「同步本地记录」导入当前账户，本地备份保留，重复同步不会重复创建相同内容。

「开始复习」先展示题目，展开后查看答案，再选择自己目前的掌握程度：

- 仍需练习：安排 1 天后复习。
- 基本掌握：至少 3 天后复习，后续间隔翻倍，最长 90 天。
- 已掌握：停止自动排期；需要再练习时可重新选择仍需练习。

这些状态是学习者自评，每次复习都会保存时间、心得与排期。完成一题后可以继续下一道待复习题。多窗口同时修改时会提示版本冲突，防止覆盖新内容。
