# 智算视界 (WisComPer) 隐私政策

**生效日期：** 2026年1月16日

智算视界（以下简称“我们”或“本平台”）深知个人信息对您的重要性，并会尽力保护您的个人信息安全可靠。本隐私政策旨在帮助您了解我们如何收集、使用和存储您的个人信息。

## 1. 信息收集

在使用本平台服务时，我们可能会收集以下信息：

*   **账户信息**：当您注册账户时，我们会收集您的用户名和加密后的密码凭证。我们不会明文存储您的密码。您可在「系统设置 → 账户与资料」中修改用户名、密码，以及设置头像与昵称。
*   **个人资料**：您可选填昵称、上传头像。头像与昵称用于在界面中展示（如顶部导航、智能体对话等），并存储在受保护的服务器上。您可随时在账户与资料中修改或更换。
*   **偏好设置**：您在使用过程中设置的选项（如默认演示模式、数学表达式字号、主题、快捷键等）可随账号同步存储，用于在您下次登录或换设备时恢复您的使用习惯。
*   **用户上传内容**：您上传至“智能识别”功能的图片文件。
*   **生成内容**：您通过本平台生成的数学公式（LaTeX代码）及动画视频文件。
*   **算式库数据**：您主动保存到“我的算式”中的公式数据及备注信息。
*   **题目请求记录**：为排查生成失败、处理滥用和管理服务，我们记录提交的题目文字（含图片识别后的题面）、账号标识、请求类型、处理状态、耗时和浏览器/系统类别，管理页仅查询最近 90 天、超期记录会定期批量清理，仅主账号 rainbow_yu 可在管理后台查看。请求记录不保存密码、Cookie、API 凭据、上传图片原文或完整代码；常见凭据格式会脱敏。该记录从功能启用后开始产生。
*   **访问日志**：为了维护系统稳定，我们的服务器可能会自动记录您的 IP 地址、浏览器类型、请求时间等基础日志信息。

## 2. 信息使用

我们收集的信息主要用于：

*   提供核心服务功能（如 OCR 识别、动画渲染）。
*   改善用户体验和优化算法模型。
*   保障账户安全，防止欺诈和滥用。

**特别声明：** 您上传的用于识别的图片仅在内存或临时存储中处理，处理完成后会定期自动清除，**我们不会将您的私有图片用于其他商业用途或出售给第三方**。

## 3. 信息存储与保护

*   **数据存储**：您的账户信息（含用户名、加密密码、头像、昵称等个人资料）、算式库数据以及您选择同步的偏好设置存储在安全的 MySQL 数据库中。头像文件与生成的视频文件存储在受保护的静态资源目录下。
*   **安全措施**：我们使用行业标准的加密技术（如 Bcrypt）来保护您的密码。修改用户名、修改密码均需验证当前密码，且通过独立弹窗完成，我们采取合理的物理、电子和管理措施来防止数据泄露。

## 4. 第三方服务

为了提供部分 AI 能力，我们可能会调用第三方大模型接口（如阿里云 DashScope）。在调用过程中，我们会对数据进行脱敏处理，且仅传输必要的文本或图像特征，不会传输您的个人身份信息。

## 5. 您的权利

您有权：
*   在「系统设置 → 账户与资料」中随时修改头像、昵称、用户名与密码；修改用户名与修改密码均在独立弹窗中完成并需验证当前密码。
*   随时查看、修改或删除您在“我的算式”中保存的数据。
*   联系我们注销您的账户（注销后所有数据将被永久删除）。
